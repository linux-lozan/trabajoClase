01 / El proyecto

Menos caos. Más evento.

AdiTech Events es una aplicación pensada para ayudar a organizar eventos tecnológicos: desde la planificación de las charlas y las salas hasta la asistencia de los participantes.

02 / Lo que se está preparando

Todo en su sitio.

01

Charlas y salas

Organización del programa, los espacios y la capacidad de cada sala.

02

Reservas

Gestión de las plazas de los asistentes cuando esté disponible el servicio.

03

Control de acceso

Preparación para validar la asistencia y agilizar la entrada al evento.

03 / Estado actual

La web es una maqueta visual.

Esta maqueta visual solo utiliza HTML y CSS. La agenda, las reservas, el inicio de sesión y el resto de funciones todavía no están conectados al back-end.
